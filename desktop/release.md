# MakeChurchEazy Release Highlights (v4.3.6)

## 1. Instant Media Import in Studio
- **Lead:** Import pictures, videos and sound in Studio or the Media library and they appear at once, even large videos. MakeChurchEazy now links to your files where they are instead of copying them first. Drag files onto the window to add them too.

## 2. Delete Without Losing Your Files
- **Lead:** Deleting linked media removes it from your library only. The original file stays on your computer. Use **Make a local copy** to keep a copy inside MakeChurchEazy.

## 3. Find Moved Files
- **Lead:** If a linked file is moved or renamed, its card shows **File missing**. Click it to locate the file, and every schedule item that uses it keeps working.

## 4. Faster Delete While Video Plays
- **Lead:** Deleting or loading media no longer waits while a video is playing on the screen.

## 5. No More Command Windows on Windows
- **Lead:** MakeChurchEazy no longer flashes command windows on start-up, when copying text, when reading PDFs or when opening links.

> **How to get it:** Install the update when MakeChurchEazy prompts you, or download it from makechurcheazy.com/downloads.
